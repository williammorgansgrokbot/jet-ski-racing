# Jet Ski Racing

A 3D arcade jet ski racer that runs in the browser as one standalone `index.html` (Three.js, no install).

**Play:** https://williammorgansgrokbot.github.io/jet-ski-racing/

- 3 tracks (Tropical Lagoon, Canyon River, Sunset Harbor), 3 laps against 5 CPU riders, buoy gates, ramps and flip tricks.
- Touch, keyboard and gamepad controls.

## Controls
| | Keyboard | Touch | Controller (Bluetooth, standard mapping) |
|---|---|---|---|
| Steer | Arrows / WASD | Left pad | Left stick (analog) or D-pad |
| Gas | Up / W | GAS | RT / R2 or A / Cross |
| Boost + flip | Space / Shift | BOOST | RB / R1 or X / Square |
| Pause | P / Esc | Pause button | Start / Options |
| Menus | Arrows + Enter | Tap | D-pad / stick, A confirm, B back |

Pair a Bluetooth controller with your device, open the page, press any button. Works with Xbox, PlayStation, 8BitDo and Switch Pro pads in Chrome, Edge and Safari.
